# Oster Conflict — S09

## Мета сесії

Перейти від умовних landmark-блоків до **reference-driven** реконструкції ключових зон Остра.

S09 використовує публічні фото, офіційні сторінки та аерозйомку як візуальні референси. Зображення не копіюються в архів; у код переноситься лише геометрична/візуальна інформація: силует, поверховість, ритм вікон, тип даху, характер ділянки, огорожі, дерева, спортмайданчики та відносне розміщення.

## Що змінено

- Музей/садиба Солонини: червоноцегляний нижній об’єм, дерев’яний верхній центральний поверх, фронтони, вхідна прибудова, сходи, віконний ритм, сад.
- Стадіон: поле 105×68 м як gameplay/reference масштаб, штучне покриття, огорожа, трибуна, службові блоки, ворота, лісистий край.
- Коледж: 4 поверхи, довгий фасад, 9-колонний ритм вікон, скляний вхідний тамбур, навіс, широкі сходи, крила та двір.
- Міський парк: головні алеї, діагональні доріжки, центральна civic-зона, лавки, активна/skate-зона як приблизний елемент за сучасними публічними матеріалами.
- Приватний сектор: замість суцільних коробок додані двосхилі дахи, вікна, двері-проксі, окремі сараї/господарські споруди, довгі двори й паркани.

## Важливо

Це ще не фінальні 3D-моделі. S09 підвищує **геометричну впізнаваність** у source-only умовах. Для фото-рівня потрібні окремі mesh/material assets у Unreal Editor/Blender.

Форма назви: **Остер**, родовий відмінок: **Остра**.
