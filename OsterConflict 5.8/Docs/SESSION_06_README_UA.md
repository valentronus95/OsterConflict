# Oster Conflict — S06: Teams / Conquest / Tickets

## Що додано

S06 переводить прототип із мережевого deathmatch-тиру в перший повноцінний командний режим.

### Команди
- Рівно дві ігрові сторони: `TeamOne` та `TeamTwo`.
- Новий гравець автоматично потрапляє в менш заповнену команду.
- `TeamId` реплікується через `AOCPlayerState`.
- Додано базові ролі: Rifleman / Medic / Engineer / Support.
- У S06 роль за замовчуванням — Medic, щоб revive можна було тестувати без меню вибору класу.
- Роль можна передати у travel URL: `?Role=Medic`, `?Role=Rifleman`, `?Role=Engineer`, `?Role=Support`.

### Friendly fire / revive
- Friendly fire за замовчуванням вимкнений на сервері.
- Постріл у союзника не віднімає HP і не дає hitmarker.
- Revive дозволений тільки союзнику.
- Revive дозволений тільки гравцю з роллю Medic.
- Дистанція, line-of-sight і 3-секундне утримання E з S05 збережені.

### Conquest
- Три прототипні точки: A, B, C.
- Точка починає матч нейтральною.
- Один бік у зоні рухає прогрес захоплення у свій бік.
- Перевага 2–3 гравців пришвидшує capture максимум у 3 рази.
- Якщо обидві сторони присутні одночасно — `CONTESTED`, прогрес зупиняється.
- При відбитті ворожої точки спочатку відбувається neutralize, потім capture.
- Capture state і progress реплікуються.

### Tickets
- Початок: 200 tickets на сторону.
- Остаточна смерть гравця: -1 ticket його команді.
- Downed сам по собі ticket не віднімає.
- Успішний revive не віднімає ticket.
- Кожні 5 секунд працює ticket bleed: сторона, що контролює менше точок, втрачає різницю у кількості точок.
- При 0 tickets раунд завершується.

### Раунд
- `Waiting / InProgress / Ended` реплікуються через `AOCGameState`.
- Після завершення стрільба сервером блокується.
- HUD показує переможця.
- Через 8 секунд точки скидаються, tickets повертаються до 200, усі гравці отримують новий командний spawn.

### Spawn zones
- Для кожної сторони є дві постійні base spawn точки.
- Біля A/B/C є окремі forward spawn точки для обох команд.
- Forward spawn доступний тільки коли команда контролює відповідну точку і точка не contested.
- GameMode серед доступних spawn points вибирає той, що найдалі від найближчого живого ворога.

### HUD / TAB
- Верхній HUD показує tickets Team 1 / Team 2.
- Показуються A/B/C та їх стан: Neutral / T1 / T2 / contested / progress.
- Показується власна команда та роль.
- TAB розділений на дві командні колонки.
- На scoreboard є kills / deaths / revives / score / ping.

## Важливо

Це все ще source-only milestone. Для реальної компіляції потрібен Unreal Engine 5.8 toolchain. Геометрія точок, spawn zones і кольори HUD у S06 тестові; фінальні позиції перейдуть на карту Остра в S07–S09.
