# S07 — Остер: центральний greybox / музей + стадіон

## Статус
S07 source milestone. Ця сесія створює перший великий міський ігровий простір і переносить Conquest із тестового квадратного полігону на структуру, натхненну центром міста Остер Чернігівської області.

## Важливе виправлення назви
- Називний відмінок: **Остер**.
- Родовий відмінок: **Остра**.
- Не використовувати форму «Остера» у проєктній документації.
- До адміністративної реформи 2020 року місто належало до Козелецького району. За чинним районним устроєм Остер входить до Чернігівського району Чернігівської області.

## Що зроблено в S07
- Новий runtime world actor `AOCWorldSectorOster`.
- Загальний greybox-полігон: приблизно **1.8 x 1.8 км**.
- 1 Unreal Unit = 1 см.
- Локальна вісь: `+X = схід`, `+Y = північ`.
- Музей використано як локальний нуль карти.
- Сектор музею/садиби Солонини отримав окрему багатоблокову форму, а не один куб.
- Поруч закладено великий центральний стадіон із полем, простими трибунами та воротами.
- Побудована перша дорожня сітка, тротуари, паркани, приватна малоповерхова забудова та дерева.
- Закладені coarse anchors для міського парку і коледжу, щоб уже в S07 правильно перевіряти масштаб усієї центральної частини. Деталізація цих зон залишається для S08/S09.
- Старі A/B/C точки перенесені з 80-метрової тестової арени:
  - `A` — музей / стадіон;
  - `B` — міський парк;
  - `C` — коледж.
- Base spawns винесені на протилежні краї великого greybox.
- Forward spawns прив'язані до нових зон.
- Weapon pickups і ammo boxes рознесені по міських секторах.
- Збережений невеликий firing lane для регресійного тесту зброї.

## Географічні опорні дані
S07 не є геодезичною копією міста. Використовується підхід "впізнавані реальні опори + геймплейне спрощення".

Перевірені/публічні опори:

1. **Остерський краєзнавчий музей / будинок В. К. Солонини**
   - адреса: м. Остер, вул. Татарівська, 30;
   - публічна координата: приблизно `50.948333 N, 30.883889 E`;
   - у S07 це `MuseumAnchor = (0, 0)`.

2. **Остерський фаховий коледж будівництва та дизайну**
   - актуальна адреса на сторінці приймальної комісії: м. Остер, вул. Соломії Крушельницької, 7А;
   - публічна координата: приблизно `50.949182 N, 30.879127 E`;
   - відносно музею грубо виходить близько 333 м на захід і 94 м на північ;
   - у S07 використано локальний anchor `(-333 м, +94 м)`.

3. **Міський парк**
   - для масштабування використано публічну координатну опору близько `50.954943 N, 30.875112 E`;
   - відносний S07 anchor приблизно `(-612 м, +735 м)` від музею;
   - точна форма, входи, меморіали, дитячий майданчик та рослинність деталізуються в S09.

4. **Центральний стадіон**
   - публічні фото/описи підтверджують центральний стадіон у музейному секторі;
   - точний footprint у S07 навмисно стилізований і буде уточнюватися за візуальними референсами.

## Що в S07 є placeholder
- матеріали;
- фасади;
- дахи;
- двері/вікна;
- інтер'єри;
- точна геометрія дворів;
- точна ширина всіх реальних доріг;
- освітлення фінальної якості;
- Nanite/Lumen art pass;
- World Partition cells;
- реальна рослинність;
- декалі, дорожні знаки, дроти, стовпи, парковані авто.

Це нормальний greybox. Спроба одразу зробити фінальний фасад кожного сараю до перевірки дистанцій була б дорогою формою самосаботажу.

## Як перевіряти S07 в Unreal
1. Відкрити `.uproject` в UE 5.8 source/toolchain environment.
2. Запустити server + 2–4 clients так само, як S06.
3. Перевірити, що світ став значно більшим за стару арену.
4. Пройти/пробігти від Museum A до Park B і College C.
5. Перевірити capture/neutralize/forward spawn.
6. Перевірити стрільбу, revive, scoreboard, tickets.
7. Перевірити колізію великих будівель, доріг і парканів.

## Джерела для reference pass
- Офіційний туристичний ресурс Чернігівщини: Остерський краєзнавчий музей / будинок Солонини.
- Офіційний сайт Остерського фахового коледжу: адреса вул. Соломії Крушельницької, 7А.
- Остерська міська громада / Державний реєстр виборців: актуальне написання адреси та Чернігівський район.
- Постанова Верховної Ради України №807-IX від 17.07.2020: сучасний районний устрій.
- Публічні фото/довідники міста для стадіону та парку використовуються лише як візуальні референси, без копіювання сторонніх asset-файлів.

## Межа цієї сесії
S07 не претендує на фінальну графіку. Її задача: **правильний масштаб, впізнавані опорні зони, мережевий Conquest на великому просторі та основа для S08/S09**.
