# SESSION 16A — Reference-driven карта Остра

**Статус:** source milestone

S16A переводить карту з приблизного city-greybox на геоприв'язаний reference-driven layout.
Це ще не фінальний art pass і не кадастрова/геодезична копія міста.

## Що змінилось

- Розмір source-only world proxy збільшено з ~1.8 × 1.8 км до ~2.4 × 2.4 км.
- Введено `FOCGeoReference`: WGS84 latitude/longitude -> локальні Unreal centimeters.
- Локальний origin: садиба Солонини / Остерський краєзнавчий музей.
- Музей, коледж, Центральний міський парк та кілька центральних історичних орієнтирів мають окремі перевірені geo anchors.
- Виправлено S09: точка `50.954943, 30.875112` більше не вважається центром Центрального міського парку. Це окрема північна park/civic reference біля будинку культури.
- Центральний міський парк прив'язано до публічно ідентифікованої точки `50.951645, 30.875861`.
- Дорожня схема стала нерегулярною/radial замість умовної прямокутної сітки.
- Додано source-only proxy Десни/заплави та р. Остер для macro-layout і майбутнього vehicle/streaming planning.
- Музей отримав додатковий silhouette pass за фасадними фото.
- Стадіон отримав track/apron, трибуни/службові маси і perimeter pass за матеріалами реконструкції.
- Коледж отримав додаткове campus massing; другорядні корпуси залишаються confidence-B до кращих фасадних референсів.
- Приватні квартали розширені й навмисно зроблені менш «ідеальними»: різні габарити, прибудови, сараї, неповні паркани.

## Джерела планування

1. **Остерська міська громада — Комплексний план просторового розвитку** (офіційний сайт громади, 2025). На сторінці опубліковані посилання на Генеральний план м. Остер, історико-архітектурний опорний план, опорний план існуючого стану та транспортну схему.
2. **Генеральний план м. Остер** — використовується як reference для macro street topology, кварталів, водних/відкритих територій і транспортної ієрархії. PDF не вкладається в ігровий архів.
3. **Чернігівщина туристична — Остерський краєзнавчий музей** — адреса Татарівська, 30 і фото/опис садиби Солонини.
4. **Остерський фаховий коледж будівництва та дизайну** — актуальна адреса: вул. Соломії Крушельницької, 7А; фото фасаду та матеріали закладу.
5. **OTG.cn.ua — реконструкція стадіону** — фото й опис штучного поля, доріжок, трибун, роздягалень, санвузлів та огорожі.
6. **Wiki Loves Monuments / публічні heritage координати** — допоміжні geo anchors центрального парку, садиби Солонини та інших центральних об'єктів.
7. Публічні фото й аерозйомка Остра — використовуються для характеру низькоповерхової забудови, дворів, рослинності та силуетів, але не вважаються survey data.

## Confidence model

- **A** — перевірена публічна координата + сильний документальний/фото reference.
- **B** — надійне публічне розташування, але неповні розміри/фасади.
- **C** — gameplay-authored archetype, що відтворює характер середовища, а не конкретний приватний будинок.

## Важливе обмеження

Приватні житлові будинки не заявляються як точні копії конкретних домоволодінь. S16A відтворює характер Остра, форму кварталів і забудову за публічними референсами. Точні landmark-моделі потребують фінальних 3D assets, матеріалів і Unreal Editor content pass.
