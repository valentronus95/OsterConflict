# S09 — Публічні референси Остра

Цей файл фіксує, на чому базується reference-driven pass. Самі фото/відео в архів не копіюються.

## 1. Остерський краєзнавчий музей / будинок В. К. Солонини

- Travels in Ukraine / travels.in.ua — фото фасаду будинку музею.
  - Візуальні ознаки: червона цегла нижнього поверху, дерев’яний зелено-блакитний верхній центральний об’єм, білі віконні рами, декоративні фронтони, вхідна прибудова, великі дерева.
- Чернігівщина туристична / chernihivregion.travel — сторінка будинку генерал-лейтенанта В. К. Солонини.
  - Підтверджує історичну будівлю 1898 року та її використання музеєм.

## 2. Центральний стадіон Остра

- OTG.cn.ua, 24.05.2021, «Велике будівництво: новий стадіон у місті Остер».
  - Фото з дрона: прямокутне зелене поле, дорога вздовж однієї довгої сторони, житлова забудова й дерева навколо.
  - Текст: штучний газон, легкоатлетичні доріжки, трибуни, роздягальні, санвузли, огорожа.

## 3. Остерський фаховий коледж будівництва та дизайну

- Офіційний сайт коледжу, сторінка «Матеріально-технічна база».
  - Фото: чотириповерховий довгий корпус із світло-бежевим плитковим фасадом, повторюваними білими вікнами, скляним вхідним тамбуром, металевим навісом, широкими сходами та високими хвойними деревами.
- Офіційна приймальна комісія: вул. Соломії Крушельницької, 7А.

## 4. Міський парк Остра

- Остерська громада / перелік об’єктів: центральний міський парк.
- «Вікі любить пам’ятки» / координатна прив’язка пам’ятного об’єкта в міському парку: приблизно 50.954943, 30.875112.
- Сучасні публічні соцмережеві матеріали: алеї, лавки, сходи, активна/skate-зона; точне розміщення окремих малих елементів у S09 позначене як приблизне.

## 5. Загальний вигляд міста

- YouTube: «Остер з висоти пташиного польоту».
- YouTube/краєзнавчі відео про Остер та канал «Остерські Хроніки».
- Візуальні ознаки, перенесені в procedural greybox: переважно низька приватна забудова, довгі ділянки, окремі господарські споруди, велика частка зрілих дерев, нерівномірна щільність забудови.

## Рівень достовірності

- A: будівля/об’єкт має чіткі публічні фото — музей, коледж, стадіон.
- B: об’єкт/парк має публічні координати та кілька загальних матеріалів, але не повний обмір.
- C: приватні будинки — reference-informed archetypes без заяви про 1:1 відповідність конкретній адресі.
