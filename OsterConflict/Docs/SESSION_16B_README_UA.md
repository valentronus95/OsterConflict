# SESSION 16B — приватний сектор, паркани та рослинність Остра

S16B продовжує reference-driven art pass після S16A. Ця контрольна точка не є фінальним арт-паком: у source-only проєкті використовуються прості proxy meshes, але структура вже розділяє різні типи парканів, дерев і трави, щоб фінальні assets підключались без переписування логіки світу.

## Додано

- високі вуличні паркани для приватного сектора;
- окремі сімейства Wood / Metal / LightSheet;
- перевага дерев'яних глухих огорож;
- бокові межі дворів простіші й часто нижчі;
- радянський міський tree palette: poplar proxy, mixed broadleaf proxy, birch proxy, pine proxy;
- окремі grass zones: mown / rough / wetland;
- паркова й стадіонна рослинність відрізняється від узбіч та заплави;
- невеликі broadleaf proxies у приватних дворах зарезервовані під яблуні/вишні/сливи/горіхи після final foliage pass.

## Важливо

Конкретний вид дерева у конкретній точці Остра не заявляється як точний без візуального референсу. Soviet-era palette використовується як історично правдоподібний набір для старих міських алей, парків і громадських територій.
