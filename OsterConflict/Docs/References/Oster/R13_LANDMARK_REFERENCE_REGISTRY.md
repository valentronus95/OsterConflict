# Oster Conflict — R13 real-Oster landmark reference registry

Status: authoritative art/layout reference list supplied by the project owner. These landmarks are not generic decoration. They must be placed against the real Oster road layout/map and used to drive unique or semi-unique environment models.

## Mandatory placement rule

- Key landmarks must be positioned relative to the real Oster street/map layout, not scattered approximately for visual convenience.
- Roads, T-junctions, parks, stadium access, landmark sightlines and the relative position of nearby objects must be preserved as closely as practical for gameplay.
- Generic Fab environment assets may be used for supporting props, vegetation and secondary buildings, but must not replace recognizable Oster landmarks with unrelated fantasy/stylized architecture.
- The playable city target is all of Oster, built sector-by-sector; Krushelnytska is only one residential reference sector, not the whole map.

## Existing residential reference

### Krushelnytska Street (former 8 Bereznia / 8 March)

User-supplied current photos establish the residential visual language:
- narrow worn asphalt without lane markings;
- sandy/earth shoulders and irregular grass margins;
- mature deciduous tree canopy;
- overhead utility wires/poles;
- low private houses of mixed age/material;
- tall/private-yard fences using wood, metal, sheet/corrugated and concrete-panel solutions;
- cars frequently parked partly on shoulder/grass;
- quiet low-density Ukrainian small-city street character.

## Art direction consequence

Reject obvious fantasy/medieval/stylized village props for Oster streets. New imported assets should be evaluated against these real references. Unique landmarks listed above require custom modelling or deliberate modular reconstruction; generic packs are support content only.
