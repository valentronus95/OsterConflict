# Work reports

This folder stores compact Markdown reports for meaningful Oster Conflict milestones and user test passes.

## Keep reports lightweight
A report should normally contain only:
- date / branch;
- reported problem or goal;
- files/systems changed;
- commit SHA(s);
- build/test result;
- remaining blocker(s).

Do not copy full compiler logs, screenshots, ZIP archives, binaries, generated Unreal folders, or large asset inventories into this folder. Link or reference them only when necessary.

Suggested filename format: `YYYY-MM-DD_short-topic.md`.
