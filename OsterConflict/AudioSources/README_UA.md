# AudioSources

Ця папка призначена для сирих аудіо-джерел перед імпортом в Unreal Editor. Фінальні `.uasset` зберігатимуться в `Content/Audio/...` після content pass.

Не додавати сюди аудіо, витягнуте з комерційних ігор. Для кожного стороннього джерела зберігати назву ліцензії та URL/чек придбання в окремому manifest.
